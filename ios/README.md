# Latent iOS

SwiftUI app, iOS 17+, iPhone only, portrait. The Xcode project is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` (no `.xcodeproj` is checked in).

```sh
brew install xcodegen
cd ios && xcodegen generate && open Latent.xcodeproj
```

- Config: `Config/Base.xcconfig` (bundle ID, `DEVELOPMENT_TEAM`, version, `API_BASE_URL`).
  Debug builds use `http://localhost:8787`.
- Tests: `bundle install && bundle exec fastlane tests` (or Cmd+U in Xcode).
- TestFlight: Actions -> TestFlight -> Run workflow, or push tag `ios-v0.1.0`
  (`bundle exec fastlane beta` does the same locally).

Full setup (Apple account, API key, certificate without a Mac, GitHub secrets, backend deploy, testers):
[`docs/TESTFLIGHT.md`](../docs/TESTFLIGHT.md).
